# F&F Daily Tasks

Frost & Flame's daily opening tasks app (PWA). Separate from the F&F Tracker, but it uses the same
Apps Script backend, the same PINs and the same sessions. Tasks come from the Opening Checklist
Google Sheet (one tab per day); ticks write back to that sheet and to its Daily log.

Hosted with GitHub Pages at https://karimullashaik0389-cloud.github.io/ff-tasks/
